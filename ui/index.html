Copy summary is the one to paste for help: plain text, short enough for a mod's Bugs tab, a forum post or a Discord message.

Copy for an AI builds the same evidence into a question you can paste into Claude, ChatGPT or any assistant you already use. Crash Doctor gathers things no chatbot can see on its own — the faulting instruction, the video memory at the moment of death, and what the sessions that ended normally have already ruled out — so handing those over is worth far more than describing the crash from memory. It also asks the assistant not to invent mod names. Nothing is sent anywhere by Crash Doctor; it only puts text on your clipboard.

Save full report as HTML writes one self-contained file — every session, every crash, the whole health list — that opens in any browser. Most help pages will not let you attach a file, so it is for somewhere that does, for a Crash Doctor bug report, or as your own before-and-after record when you change a setting or switch a mod off.

None of them contains personal data beyond your game path and hardware, and folder paths under your Windows account are replaced first.
